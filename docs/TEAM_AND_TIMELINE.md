## 风险与备选

| 风险 | 影响 | 触发条件 | 备选方案 |
|---|---|---|---|
| dlib 编译失败 | 高 | Windows + Python 3.10+ | 改 `pip install dlib-bin`（预编译） |
| 摄像头权限/无摄像头 | 中 | 演示机器无摄像头 | 提供图片上传签到作为兜底 |
| dlib 误识 | 中 | 光照差、角度大 | 提高阈值到 0.4 + 二次确认弹窗 |
| MySQL 服务起不来 | 中 | 学生机未装 MySQL | SQLAlchemy 改一行 URL 切到 SQLite |
| 5 人协作 git 冲突 | 低 | 并行开发 UI | 每人独立 feature 分支 + 每日整合 |
| 报告超 15 页 | 中 | 加内容没控制 | 用 11 号小字 + 合并图表（最低限度） |
| PyInstaller 打包失败 | 中 | 路径含中文 | 用英文路径 + `--onefile` 参数 |
| 演示视频超时 | 低 | 录制啰嗦 | 录屏时**只录关键 5 个场景** |
